How to use this page

Open your own cases file — xin_cases.json or jiajun_cases.json. Nothing is uploaded and no server is needed; the file is read in your browser.

Review the four calibration overlap cases first and compare them with the other reviewer before starting your private cases. Write a free-form, evidence-based note for each case. The Human failure label is optional and may stay empty throughout open coding — the taxonomy is written later, from the notes.

The Machine rank pattern (10-class) shown on each card is deterministic machine structure computed upstream. It is read-only context: it says where the gold titles ranked, never why retrieval failed, and it is never a failure label.
